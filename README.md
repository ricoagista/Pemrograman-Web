# 🌐 Pemrograman Web

Dokumentasi pembelajaran praktikum mata kuliah **Pemrograman Web**. Repository ini berisi modul praktikum, tugas, dan implementasi aplikasi web full-stack modern.

---

## 📁 Struktur Repository

```
Pemrograman-Web/
├── modul_0/   → Setup & Development Environment
├── modul_1/   → Fundamental Pemrograman Web Modern
├── modul_2/   → JavaScript Fundamentals & DOM Manipulation
├── modul_3/   → PHP Prosedural & PHP OOP
├── modul_4/   → Laravel REST API CRUD, Eloquent ORM & Relationship
├── modul_5/   → Autentikasi, Middleware & File Storage
├── modul_6/   → Integrasi Frontend, Dokumentasi & Deployment
└── Tugas/     → Tugas Praktikum / Final Project
```
